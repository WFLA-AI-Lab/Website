建议学习路线

  1. 先把 Python 基础打牢（变量、循环、函数、列表字典）——这是两份讲义的共同前提。
  2. 学 MODULE 01（scikit-learn）：覆盖 NOAI 笔试里的机器学习概念与经典算法。
  3. 再学 MODULE 02（PyTorch）：冲中国站上机实践需要的深度学习功底。
  4. 边学边练：进社团平台（chat.wfla-ailab.top）的 Agent 擂台，把不懂的概念问「代码助手」或「深度思考」。
